# 👋 Welcome to Hackura Labs

Hackura Labs is a student-led cybersecurity research hub and the technical engine behind **Hackura Consult**. Established at **SRI HOLDINGS**, we bridge the gap between "running scripts" and "building professional solutions."

### 🛡️ Our Mission
To secure the Ghanaian digital space by developing lightweight, high-impact security tools for SMEs and educating the next generation of African cyber professionals.

### 🎙️ Beyond the Code
We don't just build; we advocate.
* **The Podcast:** Listen to the [Hackura Labs Podcast](https://rss.com/podcasts/hackura-labs-podcast/) for insights on the Ghanaian cyber landscape.
* **The Tools:** Our GitHub is our laboratory. We build tools specifically for the African context.

### 🛠️ Core Research Areas
* **Passive Reconnaissance:** Building lightweight auditors for local SME web infrastructure.
* **Mobile Security:** Researching USSD and fintech security protocols.
* **Cyber Awareness:** Translating complex exploits into actionable defense strategies.
